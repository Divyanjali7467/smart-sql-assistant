# 🤖 Smart SQL Assistant

![Python](https://img.shields.io/badge/Python-3.10-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.60-red)
![SQLite](https://img.shields.io/badge/SQLite-Database-green)
![Groq](https://img.shields.io/badge/Groq-LLM-orange)
![Status](https://img.shields.io/badge/Status-Completed-success)

An AI-powered SQL assistant that converts natural language into SQL queries and displays the results in an interactive dashboard.

---

## 🚀 Features

✨ Convert natural language into SQL queries

✨ Execute queries automatically

✨ Interactive Streamlit dashboard

✨ SQLite database integration

✨ Groq LLM integration

✨ Fast and efficient data retrieval

---

## 🛠️ Technology Stack

| Technology | Usage |
|------------|--------|
| Python | Backend |
| Streamlit | Frontend |
| SQLite | Database |

| Pandas | Data processing |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/smart-sql-assistant.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
